# ProtoFPGA

[![UFSC](https://img.shields.io/badge/UFSC-Araranguá-blue)](https://ararangua.ufsc.br)
[![Focus](https://img.shields.io/badge/Focus-FPGA%20Development-orange)](https://github.com/LigaProtoFPGA)

**ProtoFPGA** is the academic league at **UFSC Araranguá** dedicated to rapid prototyping of
complex hardware. Mentored by professors **Ney Calazans** and **Rodrigo Pereira**, we work on
processors in FPGA, hardware accelerators, computer arithmetic and prototyping, and publish
what we learn as open material: tutorials, courses and projects.

> [!IMPORTANT]
> **No prior experience is required to join.** We value interest and the will to learn above all else.

---

### Getting started

New here? Start with the [getting started guide](https://github.com/LigaProtoFPGA/docs/blob/main/getting_started.md):
install the tools, learn the Git basics, and do your first project on the board.

### Projects

| Repository | What it is |
| --- | --- |
| [mips-s-multiplier](https://github.com/LigaProtoFPGA/mips-s-multiplier) | A Booth radix-4 multiplier that makes multiplication on the MIPS_S processor about 2.85× faster |
| [IEEE-754 vs. Posit vs. Takum](https://github.com/LigaProtoFPGA/FPGA-Based-IEEE-754-vs.-Posit-vs.-Takum-Arithmetic-) | Research in progress: three number formats compared in hardware, on precision and cost |
| [vhdl_chronometers](https://github.com/LigaProtoFPGA/vhdl_chronometers) | A countdown timer and a basketball game clock with FIBA and NBA rules |
| [mips_s_text_peripheral](https://github.com/LigaProtoFPGA/mips_s_text_peripheral) | A memory-mapped peripheral that copies a text into a MIPS processor's memory and shows it on the display |

Want to add a project or material? See [contributing](https://github.com/LigaProtoFPGA/docs/blob/main/CONTRIBUTING.md).
